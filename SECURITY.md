# Security

This is an operator tool for a trusted local Windows workstation, not a multi-user internet service. Never expose the FastAPI, WinRM or DCOM endpoints publicly.

The private local connection form sends credentials to the authenticated loopback API, which passes them through stdin to a fixed PowerShell script. They are never written to command arguments, logs or report files. Password fields are cleared after submission. Plaintext credentials transiently exist in browser, Python and PowerShell process memory; secure cleanup cannot be guaranteed by managed runtimes. Console collection still supports Get-Credential. The public static demo never collects credentials or runs remote diagnostics. Diagnostic data can still include sensitive server/account/event information. Secure the workstation, report directory, terminal and any exports. Review explicit ACLs if using an existing output directory. Administrative and SYSTEM access remains outside the application's security boundary.

The local API uses a random per-process Bearer token, a loopback client check, Host validation, an Origin allowlist and no-store responses. This does not defend against malware or another process running as the operator. Health findings use deterministic thresholds and collected event evidence. They are advisory, not a compliance certification or guarantee of availability. No automated remediation or report-driven command execution is provided.

The public demo is a static build with simulated fixture data. Do not add real diagnostic files to source, build assets, screenshots, GitHub issues or public hosting. Report a vulnerability privately to the repository owner through GitHub; do not include credentials or actual diagnostics in a public issue.

The connection endpoint validates hostnames/IP literals, rejects shell syntax and executes a fixed script with shell=False semantics, no arbitrary command input, a single-run lock and a 180-second timeout. Newly collected reports remain in memory unless exported. Only a trusted local operator may use this endpoint. Do not expose the API through tunnels or proxies.

The loopback dashboard HTML supplies the per-process API token to its own browser session in a meta tag. It is not put in a URL, persistent browser storage, public assets or public hosting. Host/Origin validation, no-store and the browser same-origin policy protect browser access; other processes running as the local operator remain outside the security boundary. A manual token field is available only for a frontend opened without this server-provided session metadata.
